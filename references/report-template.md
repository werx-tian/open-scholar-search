# 文献检索与证据分级报告模板

HTML 可直接从 `assets/report-template.html` 开始修改。报告应优先回答“哪些结论可用、证据有多直接、还缺什么”，而不是堆砌检索过程。

## 1. 数据可得性与检索记录

必须披露：

- 检索日期、使用的源、每个源的状态（可用 / 零结果 / 限流 / 不可用 / 需要授权）
- 原始检索式、实际执行检索式、适配后的平台语法
- 年份、语种、来源类别等限定条件
- 去重前后条数、开放获取解析条数
- 哪些结论仅来自题录、摘要或全文

若没有访问知网 KNS，必须明确写“未直接从 KNS 获得记录”，不得用其他来源冒充 KNS 结果。

## 2. 二维扩展坐标

每条结论都标注：

```text
对象外推轴 Sn + 概念层级轴 Lm
```

| 对象外推轴 | 含义 | 默认证据性质 |
|---|---|---|
| S0 | 目标物种/材料/人群/型号 | 直接对象 |
| S1 | 同属或高度近缘对象 | 近缘证据 |
| S2 | 同科/同类群/同类工艺 | 上位类群证据 |
| S3 | 跨类经济动物或人体 | 跨类外推 |
| S4 | 模式生物、细胞系、纯机制模型 | 机制背景 |

| 概念层级轴 | 含义 | 默认证据性质 |
|---|---|---|
| L0 | 本概念直接检索 | A 直接证据 |
| L1 | 同义词/同属扩展 | B 近缘或术语证据 |
| L2 | 科、类群或上位概念 | C 上位背景 |
| L3 | 数据驱动机制/背景概念（显式启用） | D 机制/背景证据 |

当 S/L 不在同一层时，以更弱的一轴决定最终外推强度。例如 `S1 + L0` 可作近缘证据，`S0 + L2` 只能作背景，不能直接估计本对象效应。

## 3. 核心文献表

| # | 题录 | 对象/规格 | 处理或暴露 | 结局/指标 | 主要结论 | OA | 坐标 |
|---|---|---|---|---|---|---|---|
| 1 | 标题、作者、期刊、年卷期、DOI |  |  |  |  | PDF/链接/closed | S0-L0 |

“主要结论”应描述方向和条件；涉及数值时给出剂量、单位、时间窗与比较基线。

## 4. 专题归纳

按用户真正决策的维度拆分，例如“有效性—安全性—机制—适用边界”。每条结论后附文献序号与 S/L 坐标。

建议句式：

> 在固定日投喂量条件下，提高频次主要改善饲料转化率，而不是无条件提高增重（S0-L1，文献 3、7）。

## 5. 横向汇总

| 对象 | 规格/条件 | 处理梯度 | 一致方向 | 效应量或推荐值 | 判据 | 坐标 | 来源 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

只汇总可直接比较的结果。对象、剂量、温度和投喂制度不同的研究应分栏，不强行合并为一个“最佳值”。

## 6. 规律与边界

区分：

- 跨研究稳定复现的规律
- 只在特定物种/规格/环境成立的边界
- 仅有机制解释、尚缺应用验证的假设
- 相互冲突的证据及其可能原因

## 7. 实践启示

每条建议写明适用前提、预期收益、风险和不适用范围。没有剂量、持续时间或评价标准时，不给“最佳”绝对结论。

## 8. 外推限制

必须显式声明：

- 上位层的宿主特异性、流行病学、效应量和安全阈值不得直接外推到目标对象
- 扩展层证据在摘要、表格和结论中降权呈现
- “未检出”不等于“无研究”；应披露检索范围与零结果源

## 9. 视觉与打印

- 浅色主题，正文 14~15px，表体 13.5px
- 表头 `position: sticky; top: 0`
- 证据层级用形状/文字共同标识，不只依赖颜色
- `@media print` 保留表头底色，避免表格或证据卡片跨页断裂
