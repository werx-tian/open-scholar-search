# 跨平台环境排障

主流程不依赖本节；只在命令、浏览器或进程行为异常时查阅。

## Node 与路径

- 脚本要求 Node 18+。先运行 `node --version`。
- 输出目录由公共 JSONL 写入器自动创建。路径包含空格时在 PowerShell 中用引号包住。
- 脚本本身不要求从固定目录启动；示例中的 `scripts/...` 以 skill 根目录为当前目录。其他目录调用时使用脚本绝对路径。

## 参数错误

所有脚本共享 `scripts/lib/args.js`：

- 未知参数退出码为 2。
- 缺少参数值、数字越界或枚举值不支持时，同样以用法错误退出。
- `--help` 输出当前支持的参数。

## CDP 浏览器

1. 优先使用系统 Edge、Chrome 或 Chromium。
2. 可通过 `BROWSER_PATH` 明确指定浏览器可执行文件。
3. 某些沙箱化运行时会回收一次命令结束后留下的后台进程。若 CDP 不可达，将浏览器启动和抓取放在同一进程，或使用产品提供的后台会话单独常驻。
4. 用完浏览器后关闭对应进程和临时 profile，避免占用调试端口。

## 网络失败

- `fetch failed` 表示 DNS、连接或网络层失败；`HTTP 429` 表示限流；`HTTP 401/403` 表示鉴权或访问限制。
- 站点被拦截不代表 API 不可用，分别探测站点与 API。
- 用 `node scripts/selftest.js --probe` 查看当前七个来源的状态。
- 单源失败不应中断整批任务；结果 JSONL 的 `_warnings` 会保存源、错误和时间。

## Windows 控制台乱码

CSV 自带 UTF-8 BOM。若终端显示乱码，改用 Excel 打开 CSV，或把 PowerShell 输出编码设为 UTF-8；这只影响显示，不影响文件内容。
