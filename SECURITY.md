# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or Security Advisories for this repository. Do not open a public issue for credentials, access-control bypasses, command execution, or other exploitable vulnerabilities.

Include:

- affected version or commit
- a minimal reproduction
- expected and observed behavior
- impact assessment
- any suggested mitigation

Please avoid including real API keys, personal email addresses, or private research data in reports.
